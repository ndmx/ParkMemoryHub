# Park Memory Hub Support

Last updated: April 26, 2026

## Need Help?

Park Memory Hub support covers:

- Circle invites and joining
- iCloud sync issues
- Memories not appearing on another device
- Planner sharing questions
- Radar location-sharing questions

## Before You Reach Out

Please check:

- both devices are signed in to iCloud
- iCloud Drive is available
- Park Memory Hub has permission for Photos if you want to attach memories
- Park Memory Hub has permission for Location if you want current-location tagging or radar sharing
- the app is open on both devices, or use the manual "Sync with iCloud" button in Profile or feature screens

## Common Troubleshooting

### iCloud sync looks slow

Open the app on both devices and run the manual iCloud sync button.

### A person cannot see a memory

Make sure the memory was created and shared successfully, and that the receiving device is in the same circle.

### Radar is empty

Each member must enable location sharing on their own device.

### A circle invite opened the app but nothing changed

Confirm the receiving device accepted the invite and that both devices are using the expected circle code.
